# nabu-web

Web interface of [Nabu](../nabu): the chat with the personal agent, memory, space, tasks,
connections and the administration (users, models, harness, catalog, service agents, clients, usage,
audit). React 19, TypeScript, Vite; five interface languages.

- Specification and mockups: `hammurapi-specs/specs/NAB/CMN/FTR.NAB.CMN-0001`
- Development guide: [AGENTS.md](AGENTS.md)

```sh
npm ci && npm run dev    # http://localhost:5173, API on localhost:8080
```
